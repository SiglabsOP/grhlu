Protodata Backup

Personal desktop backup tool · last updated 25 November 2026

Protodata Backup is a private, personal Windows desktop application. It creates an encrypted backup archive of the owner's own files and stores a copy in the owner's own Google Drive. It is not offered to the public.

Privacy Policy

The app requests only the Google Drive scope https://www.googleapis.com/auth/drive.file, which allows it to create files and to see or delete only the files it created itself. It cannot read any other files in your Google Drive.

  • Data accessed: only the backup archives and the backup folder created by the app.
  • Data storage: the Google sign-in token is stored only on the user's own computer. No data is sent to the developer or to any third party.
  • Data sharing: none. The app has no server, no analytics, no advertising.
  • Revoking access: click "Disconnect" in the app, or remove access at myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Terms of Service

This software is provided for personal use by its owner, "as is", without warranty of any kind. The user is responsible for keeping the archive password safe; encrypted backups cannot be recovered without it.
